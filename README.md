# IDS PhD Program (Public Site)

[Carlson School of Management](https://carlsonschool.umn.edu/), [University of Minnesota](https://twin-cities.umn.edu/)

This repository is a public, GitHub-based website providing supplemental information related to the Information and Decision Sciences (IDS) PhD program at the Carlson School of Management, University of Minnesota.

## Commands

* `mkdocs serve` - Start the live-reloading docs server.
* `mkdocs build` - Build the documentation site.
* `mkdocs -h` - Print help message and exit.
* `mkdocs gh-deploy` - Deploy the site to GitHub Pages.

## Project layout

    mkdocs.yml    # The configuration file.

        index.md  # The documentation homepage.
